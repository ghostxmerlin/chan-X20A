围观模式怎么工作 · 怎么判断是不是在跟它说

← 观察台

围观模式（代码名 crowd，机器人屏幕上显示 MEET）：用听觉、视觉，再加上情景和纪要来聊天。这一页画的就是它：现在用鹿野（ly01）的声音，人设是“傲娇霸气”。第一张图是线上现在的样子；第二张图是接下来要接上的“是不是在跟它说”的判断，多数还在计划里，每个框都标了状态。

① 听

麦克风的声音一直传到 ear。ear 先降噪，再用自己的 VAD 判断有没有人在说话。

  • 送给模型：只送说话的那几秒（前面多留 0.8 秒，后面多留约 1.6 秒），安静的时候不花钱。
  • 不能打断：hello 自己出声、在想、说完 0.6 秒内，一点声音都不送。
  • 模型断句：模型那边再用自己的 VAD 断句（阈值 0.6，静 1 秒算说完）。
  • ear 自己也识别（SenseVoice），用来：写进库给纪要和情景用、找关键词（看图 / 查询 / 注意看 / 闭嘴）、救回「嗯」。
  • 关键词耳朵（新，只观察）：直接听原始声音，不靠切句子，按声音认名字「デュナメス」，命中写进 log.html。现在还没有人用它的结果，见下方 ⑦。

② 看（三条路）

  • M12 实时认脸 → 眼前的人：变了就重发说明（最多 3 秒一次），也用来招呼主人、单击打招呼。
  • 机身摄像头 → eye：画面变了才上传；eye 每分钟挑最多 6 张识图一次，写成“摄像头照片识图（大约一分钟前）”，也进情景。
  • 视觉爆发：听到「注意看 / 仔细看 / 你看看…」或看图问题后，20 秒内拍一张、认一张、再拍下一张（约 2 秒一张）。每张变成一行“注视”，保留最新 5 张、3 分钟内的。

③ 情景和纪要（每分钟，不直接说话）

  • 纪要（notes）：每分钟把正在进行的对话缩成一段，整分后约 15 秒写好；每 5 分钟留一条，组成“最近半小时聊过”。
  • 情景（mind）：整分后约 20 秒，把这一分钟听到的句子、声音种类、M12 认出的人、eye 识图和当时的纪要合成“此刻的情景”。没有新东西就沿用上一分钟，不调模型。
  • 这两样都不直接给模型，而是先放进库，再由 ④ 拼进说明。

④ 拼成说明（session.update）

会话打开时、之后每 30 秒，ear 向 mind 要一次背景（GET /realtime/context：只读库，不调模型，不花钱），拼成：人设 + 【背景】 + 【刚才的对话】 + 【你的眼睛】，整份发给模型。

什么时候重发（日志 call.realtime.context 的 why）：

context每 30 秒，背景更新
seen眼前的人变了（最多 3 秒一次）
looks来了新的注视照片（最多 3 秒一次）
replyhello 每说完一句

【背景】最多 2600 字：现在时间、地点（不知道时 10 分钟最多问一次）、背景资料、此刻的情景 / 在聊 / 声音（4 分钟内的）、对话纪要、M12 认出的人（3 分钟内）、画面、注视、最近的情景（半小时、最多 8 行）、最近半小时聊过、最近的纪要（3 小时内 4 条）、你记得（最多 3 条）、认识的人（人物卡）。【刚才的对话】里重复说过的话会标上次数，让它别再说。

⑤ 回答闸门（每轮）

模型的回答文字比声音早 0.3–0.6 秒到，闸门按顺序看：

  1. 看图问题（你看看 / 这是什么 / 拿的是什么…）→ 这次回答不放（wait_look），开视觉爆发，马上放一句录好的「我看看哈」；拍到问题之后的第一张照片，就把照片描述当文字给它，让它照着答。8 秒没等到就不说。
  2. 查询问题（查一下 / 搜一下 / 天气 / 新闻…）→ 不放（wait_search），放「我查查哈」；ear 自己用 qwen3.8-flash 强制联网搜（最多等 10 秒），把结果当文字给它，用自己的话说。没搜到就说没查到。
  3. 只回了「嗯」 → 不放（quiet）。5 秒内如果那句话里有叫它、问它的词，或者是它刚说完 20 秒内的问句，就用文字再问一次（救回）。
  4. “没听清 / 说啥 / 啥意思” → 不放（unclear）。
  5. 和最近说过的一字不差（6 个字以上）→ 不放（repeat）。
  6. 5 秒内没有新照片却说“看不清 / 黑乎乎 / 全白” → 不放（blind）。
  7. 其余 放行：声音转成 Opus（60 毫秒一帧），经 /mouth 发到机器人喇叭。

不放的回答已经算过钱（约 0.004 元一轮），只是不播。

⑥ 招呼、闭嘴、会话开关

  • 主人出现：M12 认出主人，离开 1 分钟以上再出现 → 长招呼（喊名字，10 分钟最多一次）；10 分钟内再见 → 短招呼（hi / 你好 / 嗯哼？/ 嘿，或者两声哔；最多 1 分钟一次）。
  • 单击屏幕：看最近 2 秒最大的那张脸：认识的叫名字；不认识的按 M12 的性别年龄叫美女 / 帅哥 / 小朋友 / 爷爷 / 奶奶；没有脸就说没看到人。
  • 招呼都等 hello 安静了才说，等超过 10 秒就作废。
  • 闭嘴：听到「闭嘴」，或者“别说话 / 安静点…”这样的短句 → 让 mind 关掉“围观”开关，会话马上断开。数字 1 或双击屏幕再打开。
  • 会话：机器人报告在围观、“围观”开关开着、/mouth 连着，三样都满足才开。每段最长 10 分钟就换一段新的（刚才的对话会带过去）；3 分钟没人说话就关，下一句话或者主人出现时再开。
  • 围观开着时，本地的情绪台词不回应；模型自己也开着联网搜索，但它常常不搜，所以有 ⑤ 里 ear 自己强制搜这一步。

⑦ 关键词耳朵（已上线 · 只观察）

名字「デュナメス」是夹在中文里的日语，SenseVoice 每次写成不同的字（Dナ、B南米、叮那米、点到名…），所以只认声音、不经过文字。

  • 怎么听：直接拿原始麦克风声音，每 0.25 秒看一次最近 1.5 秒，不靠 VAD 切句子（小声叫它，VAD 常常切不出句子）。比背景高不到 4 dB 的不看。
  • 怎么认：中文 HuBERT 把声音变成特征，和录下的样本做 DTW 对齐；名字分 4 段，每段都要对上（「嗯」「Yeah」对不齐）。低于 0.50 命中，0.50–0.55 差一点。
  • 实测（2026-11-17）：主人当天 24 声 24 声认出（只用别的会话的样本）；下午 37 分钟会话回放 9/9 命中、其余 0 误报；前几天 1.9 小时说话 0 误报。别人的声音还没测。
  • 延迟：命中马上报，约 0.3–1.3 秒（服务器忙时更慢）。本地 CPU，不花钱，不受付费开关和暂停影响。
  • 现在：命中只写进 log.html（「听到关键词」），mind、围观都还没用它。

⑧ M12 0.2.0 能多做什么

新增：每张脸的朝向和距离，和一串事件（有人进来 / 走了、转过来看、点头 / 摇头、歪头、靠近 / 走远、捂镜头、开关灯、待机时被叫醒）。固件正在接，还没刷机，先只把事件显示出来。

  1. 有人 / 没人，省钱待机：进出按人记编号，背对着也算在场，补上“主人在但没露脸”的漏洞；没人时 M12 真休息，有人进来马上醒、还能叫出名字。
  2. 捂眼睛：短捂躲猫猫，长捂 = “别看我”，关掉视觉付费。判断的是镜头被挡，不受距离影响，是最稳的事件。
  3. 看着它 + 叫名字 = 在跟我说：接进上面第二张图。
  4. 之后：点头 / 摇头当是 / 否（只在 0.5 米测过）、歪头模仿、靠近害羞、关灯道晚安（晚上没测）、同一个人编号不变 → 认人更稳。

上机先看心跳：版本 0.2.0、帧率不低于 14.7、丢包 0。姿态字段很占串口带宽，2 张脸加人形已接近上限。

⑨ 分阶段（每步主人能看到什么）

P0影子判定（只改服务器，行为不变）：log.html 每句话带上「叫名字 · 句首」「转过来 1.2 秒」「影子：会开口」。
P1围观用上关键词耳朵：喊 Dynames 不会再被压成「嗯」。
P2被叫反应：任何模式下喊它，眼睛和头都有反应，不花钱。
P3陪伴对话窗：旁人聊天它不插嘴，叫它再接上（先测别人的声音）。
P4围观先打分再付费：分数不够就不让模型生成，省掉没播出的回答的钱；脱口秀被叫就停。
P5第二级校验器：只有测出误报才做（合成数据已备好）。

要主人定的一件事：长时间没说话之后，“叫名字”是代替 hello，还是两个都算。
