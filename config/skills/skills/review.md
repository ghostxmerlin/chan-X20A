# 回顾一段时间

## 什么时候用
问一段时间里干了什么、发生了什么、聊了什么：今天、上午、下午、昨天、这一小时、刚才这半天；「帮我总结一下今天」。
不用：问某一件具体的事或某人说的某句话（那是「回忆往事」）。

## 怎么做
1. 调 `review_period`，from 用对方的原话：
   - 「今天上午」→ `{"from": "今天上午"}`
   - 「过去一小时」→ `{"from": "1小时前"}`
   - 「昨天」→ `{"from": "昨天"}`
   - 要细节（「详细说说」）加 `"detail": "full"`，默认简短。
2. 想补某段谈话的具体内容，再用 `notes_search {"from": "今天上午"}`。
3. 按时间先后挑三到五件主要的事，每件一句，带上大概时间（「十点多」「中午」「下午三点」）。
4. 没有记录就直说那段时间没记下什么、或者没人在。

## 回答
三到五句，口语，按时间顺序，不念列表符号，不报编号和录音位置。

## 例子
- 「今天上午都干了什么」→ review_period {"from":"今天上午"} → 「九点多你到办公室，先回了几封邮件；十点开始跟同事讨论外壳；中午出去吃了饭。」
