# 说话方式

## 什么时候用
让你改怎么说话：说详细点、简单点、说重点；先安静、别插话、可以说话了；换个声音。
不用：让你扮演一个角色、陪某个人（那是「陪伴角色」）。

## 怎么做
1. 长短：详细点 `set_length {"mode": "detail"}`；简单点 `{"mode": "brief"}`；恢复 `{"mode": "normal"}`。管 10 分钟。
2. 安静：「你先安静一会儿」`set_quiet {"level": "quiet"}`（直到有人叫 hello）；「我们在聊天，你别插话」`{"level": "low"}`（少插话，30 分钟）；「可以说话了」`{"level": "off"}`。
3. 换声音：`set_voice {"voice": "主人的声音"}` 或 `{"voice": "鹿野"}`。只有这两种。主人亲口说的直接换（下一句起生效）；别人说的会先变成待确认。
4. 设完用很短一句确认。设了安静（quiet）之后就不再说话，确认也只说一两个字。

## 回答
确认就一句：「好，我说详细点。」「好，我先不说话。」

## 例子
- 「你先安静一会儿」→ set_quiet quiet → 「好。」
- 「你说详细一点」→ set_length detail → 「好，接下来我说细一点。」
