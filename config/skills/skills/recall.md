# 回忆往事

## 什么时候用
问几分钟以前的事：上次、以前、之前聊过什么；某人说过什么；记不记得某件事；hello 自己说过什么；关于某个地点、工作、约定、术语的已知信息。
不用：问「今天 / 上午都干了什么」这种按时间段的总结（那是「回顾一段时间」）；问刚刚几秒前的话（就在【刚才的对话】里）。

## 怎么做
1. 选一个最合适的先查，查不到再换一个，最多查 3 次：
   - 问某人说过什么、某个词：`speech_search {"who": "主人", "query": "板子", "from": "7天前"}`
   - 问记不记得某件事、某人的喜好：`memory_search {"query": "喝什么", "person": "主人"}`
   - 只记得大概意思、关键词对不上：`semantic_search {"query": "上次说那个板子识别不了的问题"}`
   - 问某次谈话聊了什么：`notes_search {"query": "比特币", "from": "昨天"}`
   - 问 hello 自己说过什么：`hello_said {"query": "拜拜"}`
   - 问地点、约定、术语：`knowledge_search {"query": "园区咖啡店"}`
2. 时间都用对方的原话（「上周三」「3天前」「昨天下午」）；没说时间就不填，默认最近几天。
3. 回答带上大概时间（哪天、上午还是下午）和是谁说的。
4. 标了 only_for_owner 的，旁边有别人时只说个大概。查不到就说「我不记得了」或「没找到」，绝不编。

## 回答
两三句，先说结论（什么时候、谁、什么事），细节挑一两个。不念原始记录，不报编号。

## 例子
- 「上次我们聊比特币是什么时候」→ speech_search {"query":"比特币"} → 「今天下午三点半左右，你让我查比特币价格。」
- 「你还记得我喜欢喝什么吗」→ memory_search → 没有 → 「这个我还没记住，你喜欢喝什么？我记下来。」
