# 帮我调试

## 什么时候用
主人说「进入调试模式」「帮我调试」「陪我调试」，可以带时长（「调试一个小时」）；调试模式中主人问调试的事：刚才那个值多少、这是第几次了、从头到现在试过什么、你怎么看、退出调试、要不要总结。

## 怎么做
1. 进入：`set_debug {"on": true}`；主人说了时长就加 minutes（「一个小时」= 60）；没说时长就不填，一直到主人说退出。说一句「好，我在旁边帮你记着」这样的话就够。
2. 调试中：你在旁边安静地听、帮他记，不插话、不搭腔、不评论。只有叫你的名字、hello，或点屏幕时才回答。
3. 主人问记录（刚才的值、第几次、试过什么）：先 `debug_log`，可以带关键词 `debug_log {"query": "电流"}`，照记录答：时间、次数、读数照记录说，记录里没有就说没记到（记录每两三分钟才更新，刚说的可能还没进来）。
4. 主人问技术问题（为什么会这样、怎么解决）：先看 `debug_log` 知道在调什么，再 `doc_answer` 查资料推理。
5. 收到「调试中你发现了一件事」的[事件]：照着说一句提醒，具体、短，说完就停。
6. 退出：`set_debug {"on": false}`，然后问一句要不要总结这次调试（只问，不要自己总结）。主人说要，再 `debug_summary`，照 spoken 说；要细节再说 tried 和 open。

## 回答
短：调试中的回答一两句，先给数或结论。不念整份记录。
