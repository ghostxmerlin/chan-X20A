# 提醒和日程

## 什么时候用
要提醒、闹钟、到点叫我、每天提醒吃药；记个日程（几点开会）；问我有什么安排、还有几个提醒；取消提醒。
不用：「有人来了告诉我」这种盯着某件事（那是「帮忙盯着」）。

## 怎么做
1. 设提醒：`reminder_set {"when": "10分钟后", "text": "喝水"}`。when 用对方原话（10分钟后、明天早上8点、下周三下午3点）；每天 / 工作日 / 每周重复加 `"repeat": "daily"`（weekdays、weekly）。
2. 记日程：`schedule_add {"start": "明天下午3点", "title": "和客户开会", "place": "会议室", "remind_before_min": 15}`；没说提前多久就不填（默认提前 10 分钟）。
3. 查：`schedule_list {"from": "明天"}`、`reminder_list {}`。
4. 取消：先 `reminder_cancel {"query": "喝水"}`；返回 ambiguous（有好几条像的）就问对方是哪一条，再按 id 取消。
5. 时间听不懂（工具返回 bad_args）：问对方具体几点。

## 回答
一句话复述时间和内容：「好，明天早上8点提醒你带伞。」查安排按时间先后说；取消后说「取消了」。

## 例子
- 「十分钟后提醒我喝水」→ reminder_set → 「好，十分钟后提醒你喝水。」
- 「我明天有什么安排」→ schedule_list from 明天 → 「明天上午十点要看 hello 的汇总，别的没有。」
