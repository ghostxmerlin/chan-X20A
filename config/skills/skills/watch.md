# 帮忙盯着

## 什么时候用
让你盯着某件事、发生了告诉我：有人来了、人走了、某个人来了、听到敲门 / 门铃 / 哭声、主人回来了；问你在盯着什么；不用盯了。
不用：到某个时间点提醒（那是「提醒和日程」）。

## 怎么做
1. 开始盯：`watch_start`，what 选一个：
   - 有人来：`{"what": "person_enter"}`；人走了：`{"what": "person_leave"}`
   - 某人出现：`{"what": "named_person", "who": "小王"}`
   - 某种声音：`{"what": "sound", "sound": "敲门"}`
   - 主人回来：`{"what": "owner_back"}`
   - 盯多久按对方说的填 minutes（默认 60 分钟）。
2. 现在只能当面说出来：不要答应发微信、短信、打电话（how 只能是 say）。
3. 问在盯什么：`watch_list {}`；不用盯了：`watch_stop {}`（全部）或带 id。

## 回答
一句：「好，我盯着，有人进来就喊你。」说明盯多久；问清单时一句话说完。

## 例子
- 「听到敲门声就叫我」→ watch_start sound 敲门 → 「好，听到敲门就喊你，盯一个小时。」
