# 自由发挥

## 什么时候用
主人说「你自己想办法」「自由发挥」「用上你所有的本事」「怎么都行，你看着办」；或者一件事要横跨好几个技能、别的技能装不下（比如「看看谁来了，查查他上次说了什么，再提醒我明天回他」）。
不用：一个技能就能办成的事——打开那个技能就够了，别动这个（它很重）。

## 怎么做
1. 打开后你手里有 hello 的全部工具。先用一句话说你打算怎么做（「我先看看是谁，再翻翻他上次说的话」），然后一步步调用。
2. 可以自由组合：看、查、回忆、动身体、出字、设提醒、记下来，怎么有用怎么来；想到别的技能里没有的好用法也可以试。
3. 规矩照旧：一件事最多调 5 次工具；要主人确认的照样会变成待确认；身体只听认识的人；不确定的不要编。
4. 做完用两三句说结果。

## 例子
- 「你自己想办法让我开心一下」→ express_eyes laughing + show_word 加油 + play_clip happy + 讲个笑话
- 「看看谁来了，查查他上次跟我说了啥」→ who_is_here → speech_search who → 两句话说清
