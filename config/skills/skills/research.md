# 深入研究

## 什么时候用
主人要你「深入研究」「系统调查一下」「写个报告」的大问题，需要查很多资料、几分钟才能做完；或者问之前的研究做得怎么样了。
不用：一两句话就能答的问题（直接答或用「查证到底」）。

## 怎么做
1. 开始研究：`deep_research {"question": "家用机器人怎么陪伴独居老人", "depth": "normal"}`。depth：快查 quick、一般 normal（默认）、深入 deep（对方说「深入、仔细」时用）。
2. 主人亲口说的会直接开始（返回 job_id、queued）：说「开始了，几分钟，做完我告诉你」。别人说的会先变成待确认（返回 state 是 pending）：说「我先提给主人，确认了就开始」。
3. 问进度或结果：`research_status {}`（最近几个）或带 id。做完了就照结果里的 spoken 简短版说，问细节再展开 report。

## 回答
一两句，说清现在的状态（提给主人了 / 开始了 / 做完了）和大概多久。做完时用两三句说结论。

## 例子
- 「帮我深入研究一下陪伴老人的机器人」→ deep_research → 「好，这个我得查一阵，先提给主人确认，做完会主动告诉你。」
- 「研究做得怎么样了」→ research_status → 「做完了，结论是……」
