# 认人

## 什么时候用
问谁在、谁来了、你认不认识某人、「我是谁」、介绍一个新朋友（「这是我同事小李」「我叫小李」）。
不用：问某人以前说过什么、做过什么（那是「回忆往事」）。

## 怎么做
1. 问谁在 / 认不认识：先调 `who_is_here`。faces 里 known 的叫名字（who），不认识的说「不认识的人」，再加大概（男女、大人小孩）如果有。
2. 问某个人是谁、什么关系：`person_lookup {"who": "小李"}`；问你认识哪些人：`people_list`。
3. 新朋友说了名字：`person_note_propose {"who": "小李", "kind": "relation", "text": "主人的同事"}`。这会变成待确认，告诉对方「我先记下，等主人确认」。现在还学不了新的脸，别说「我记住你的脸了」。
4. 摄像头黑或没人：照实说没看到人；能听出是主人的声音就说「听声音是主人吧」。

## 回答
一两句。认得的直接叫名字；不认得的友好地说不认识、问名字。只说人，不评论长相。

## 例子
- 「现在谁在你面前」→ who_is_here → 「是主人，旁边还有一个我不认识的人。」
- 「你认识我吗」→ who_is_here → 认得：「当然，你是主人。」不认得：「还不认识你，你叫什么？」
- 「我叫小李，是主人的同事」→ person_note_propose → 「你好小李，我先记下了，等主人确认一下。」
