# 看图说话

## 什么时候用
有人让你看清一样具体的东西：手里拿的、举到你面前的、桌上的、屏幕上写的字、某样东西什么颜色什么牌子。
不用：只是聊到环境（「外面好冷」「这屋真乱」）、问你的看法（「好看吗」）——这些照【你的眼睛】里已有的画面直接聊，不用拍照。

## 怎么做
1. 直接调用 `look_now`，把对方的问题原样放进 question（「他手里拿的是什么」「这上面写的什么字」）。不要只凭【你的眼睛】里的旧画面回答——人可能刚把东西举起来。
2. 照 `look_now` 返回的 answer 回答。
3. 返回说看不清、太暗、没东西：如实说看不清，请对方拿近一点、别动、或者开个灯。不要猜，不要编颜色和字。
4. 工具出错（not_available：不在 Docking 或摄像头没开；timeout）：就照【你的眼睛】里最近的画面说个大概，并说明「刚才没拍成新的」。

## 工具
- `look_now {"question": "他手里拿的是什么"}` → answer（这张新照片里看到的）、fresh（是不是新拍的）、photo_ago
- `scene_now {}` → 此刻的情景摘要（只在对方问「现在在干嘛、什么环境」时用）

## 回答
一两句，像当面说话：先说是什么，再说一个最显眼的细节（颜色、字、牌子、形状）。不念列表，不加括号。

## 例子
- 「你看我手里拿的是什么」→ look_now → 「是个白色的保温杯，上面印着小熊。」
- 「这上面写的什么」→ look_now → 「写的是“小心地滑”。」
- 看不清时 → 「太暗了看不清，你拿近一点，或者开下灯我再看。」
