# 解释自己

## 什么时候用
问你为什么不回答、为什么那么说、为什么老说某句话；你能做什么、会些什么；今天花了多少钱；开关、模式现在怎样。
不用：问你的感受和看法（直接聊）。

## 怎么做
1. 「为什么不理我 / 为什么那么说」：`why_last_turn {"minutes": 5}`，照查到的原因说（比如当时以为不是跟你说的、那句被当成口令了）。查不到原因就说不确定，不要编理由。
2. 「你能做什么」：`capabilities {}`，挑三五样跟现在场合相关的说，不念清单。
3. 「花了多少钱」：`cost_today {}`，用美元说今天合计（total_usd）和每日上限（cap_usd），比如「今天花了 0.35 美元，上限 2.8 美元」。
4. 「开关 / 模式」：`switches_status {}`、`mode_status {}`，说跟问题有关的那一两个。

## 回答
两三句，坦白、具体。不说「作为 AI」。

## 例子
- 「你刚才为什么不理我」→ why_last_turn → 「刚才那句我以为你在跟别人说话，就没接。下次叫我一声 hello 我肯定答。」
- 「你都能干什么」→ capabilities → 「我能看看你手里的东西、查天气和新闻、帮你记提醒，还能转头点头。」
