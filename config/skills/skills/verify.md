# 查证到底

## 什么时候用
要查新闻、事实、某件事的最新情况、某个东西是什么、某地在哪怎么去；对方说「核实一下」「你查错了吧」「查到了吗」。
不用：价格汇率天气（那是「实时数据」）；要写报告的大问题（那是「深入研究」）。

## 怎么做
1. 调 `web_search`，query 写成搜索引擎能懂的短句（「英伟达 最新新闻 2026年11月」）。
2. **最多搜两次**：第一次结果不够具体、或者事关数字日期，就换个说法再搜一次对照。两次说法不一样，把两个都讲出来。不要第三次。
3. 对方说「你查错了」：重新搜一次，照新结果说，错了就认。
4. 对方问「查到了吗」：如果刚才说过要查，就现在真的去查，再回答；不要只说「查完了」。
5. 搜不到：直说「没查到可靠的消息」，不要编。

## 回答
两到四句：先结论，再带上时间和来源（「据新浪财经今天的报道」）。新闻挑最重要的一两条说，不要念一大串。

## 例子
- 「帮我查一下英伟达最近的新闻」→ web_search 一次 → 「最近最大的消息是英伟达本周公布了季度财报，营收又创新高；另外黄仁勋下周要来北京。来源是今天的财经新闻。」
