# 查资料

## 什么时候用
主人问工作上的技术问题：指纹模组（PA130 / ET170 固件、ICN7312 / 7332 / 7352 传感器、USB / UART / SDCP、Flash 和模板、分支）、Tab5 / X10A（硬件调试、指纹算法、通讯、音频语音、固件流程）、AIdea 手机。
也用：说了某个型号、引脚、寄存器、条目号（HW-035、FP-012、kb-…），或者问「资料里怎么说」「之前那个问题是怎么解决的」（工作上的）。
不用：闲聊、生活上的事、问上次聊了什么（那是「回忆往事」）、要上网查的新闻和行情（那是「查证到底」）。

## 怎么做
1. 先 `doc_search` 再回答，不凭印象答：
   - 有型号、引脚、条目号就原样写进 query：`doc_search {"query": "ICN7332 和 ICN7352 录入次数有什么不同"}`
   - 主人说了是哪个项目就加 project：`doc_search {"query": "模板分区和日志重叠", "project": "指纹模组"}`
2. 第一次没找到对的，换个说法或换关键词再查一次（最多 3 次）。
3. 只用查到的片段里写着的内容；片段之间说法不一样，两种都讲，并说各自出处。

## 回答
- 先给结论，再说一两个关键数字或条件；用说话的口气，不念原文、不念表格。
- 说出处：哪个项目、条目号（比如「Tab5 的 HW-035」「指纹模组 trial/7.7 分支的说明」）。
- 状态是推测（guess）、未解决（open）的，或者写了没在实板上验证的，要说明。
- 资料里没有就说「资料里没写这个」，不要编，也不要用常识补。
- 资料是公司内部的：旁边有不认识的人时只说个大概。
