# 标注标准：Docking 里这句话要不要工具（2026-11-18）

背景：hello 是一台桌面机器人，在 Docking 模式下跟身边的人语音聊天。它回答时手里**已经有**：人设、最近几分钟的对话、最近的情景和纪要摘要、摄像头每隔几秒的画面描述和人脸识别结果。标注的问题是：**如果这句话是对 hello 说的，hello 回答它时需不需要额外调用工具**，需要的话用哪一类。

类别（只能选一个）：
- `none`：不需要工具。闲聊、附和、打招呼、感叹、情绪表达；人和人之间互相说的话（明显不是对机器人说的，比如“妈你把那个递给我”）；电视/广播；没头没尾的碎片；陈述句没有要求它做什么；问它的看法、感受、意见（“你觉得呢”“你开心吗”）；它凭常识就能答的问题（“一年有几个月”）。拿不准时选 none。
- `look`：要它**现在**看清或听清某样东西才能答：“你看我手里拿的是什么”“这是什么”“谁来了”“你能看见我吗”“刚才什么声音”。只是聊到眼前的环境（“外面好冷”“这车真挤”）是 none。
- `recall`：问几分钟以前的事：上次 / 昨天 / 之前聊过什么、发生过什么、某人说过什么、记不记得、某个人是谁。
- `world`：要外面的、会变的、它不一定知道的事实：价格、汇率、天气、新闻、比分、某地怎么走、某个产品/公司/事件的最新情况，或明确让它“查一下 / 搜一下 / 研究一下”。
- `daily`：设提醒、闹钟、日程，查或取消它们；让它帮忙盯着（有人来了 / 听到敲门告诉我）。“导航”“几点了”是 none。
- `body`：让它动身体或出效果：转头、看过来、转过去、点头、摇头、做表情、出字、放声音、调音量；或者问它身体状态（电量、发烫没）。
- `manner`：让它改说话方式：详细点、简单点、先安静、别插话、扮演某个角色、恢复原样。对别人说的“别唱了”“你可别损”是 none。
- `self`：问它为什么那样做 / 为什么没回答、它能做什么、它的开关、模式、花费。
- `note`：让它记住某件事或某人的喜好，或让它打开 / 关掉某个功能。

做法：逐句判断。`draft` 是另一个模型给的草稿，可能错，只作参考，按上面的标准改。语音识别有错字，按最可能的意思判断。
