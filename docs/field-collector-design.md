# 肩上采集观察台 · 设计与数据约定

面向携带 StackChan 外出时的真实画面、头部运动和遥控操作观察。沿用原生 Android 横屏界面，不添加新的前端依赖。

## 视觉方案

- 纸白 `#F3F5F2`：大背景与曲线底色。
- 墨蓝 `#233B4A`：标题、读数和视频边界。
- 灰蓝 `#617780`：辅助信息与网格。
- 轴蓝 `#3574C4`：X 轴。
- 松绿 `#178577`：Y 轴、主操作。
- 陶橙 `#C56D32`：Z 轴、录制标记。

系统无衬线字体保证中文可读；页标题 18 sp、图表标题 14 sp、辅助文本 11–12 sp、轴值使用等宽字体 11 sp。用分隔线与留白分组，不使用重复卡片、阴影或装饰渐变。曲线动画只来自实际数据，刷新约 20 Hz。

```text
观察台 / 肩上采集                         连接状态   设置
┌──────────────────────┬──────────────────────────────┐
│                      │ 加速度 · 含重力   X / Y / Z   │
│  机器人第一视角       │ 最近 8 秒三轴曲线 + 合加速度  │
│  4:3 等比例           ├──────────────────────────────┤
│  分辨率 / 实收 fps    │ 角速度 · 头部坐标 X / Y / Z  │
│                      │ 最近 8 秒三轴曲线 + 转动强度  │
├──────────────────────┼──────────────────────────────┤
│记录状态 / 记录 / 打标 │ 遥控目标 · 舵机反馈 / 控制开关 │
│电量 / Wi-Fi / 小触摸条│ 电平 / 历史记录（向下滚动）     │
└──────────────────────┴──────────────────────────────┘
```

审视：不以触摸状态或内部堆内存占据首屏；首屏呈现运动变化，低频触摸收为一行。零值、断流、尚无遥控包和传感器无效必须可区分。遥控器不定时发心跳，因此使用“最近输入”，不据包龄宣称连接失效。目标角和反馈角使用不同线型/标识，不用同一个数冒充两者。

## 数据约定

保留六轴原始量，设备时间、样本序号、接收时间、帧序号、遥控包和舵机读回状态。BMI270 在运动头部，数据包含走路、安装姿态、转头和重力；没有经过机身安装标定，不标成身体线加速度、GPS 轨迹或绝对航向。肩部振动概览使用合加速度相对 1g 的偏离，仅用于直观观察。

运动读取目标 50 Hz，硬件 ODR 100 Hz，使用 2 秒环形缓存批量取回；记录明确缺样，不把 Android 约 10 Hz 的页面刷新率当成传感器采样率。加速度量程 ±8g，陀螺仪 ±2000°/s。画面帧率使用实际收到的不重复图像计算。

ESP-NOW 与采集 Wi-Fi 共用无线频道，显示机器人当前频道，官方遥控器切到同频道，目标 ID 0（广播）或 1。遥控器的原始摇杆、模式和自身 IMU 不在官方 8 字节包内，不能由机器人准确恢复。辅助按钮只采集状态，不驱动未配置的 GPIO2 附件。

2026-10-31 用户明确要求开启转头与声音、匹配原厂遥控行为。0.3.2 调整为开机准备独立接收器，不归位、不重写原厂零点，等新的遥控输入。停止/重新启用不重放旧包；位置回传无效时仍停止。速度采用遥控包的 0…1000（官方通常 600），保留原厂平滑、到位释放和俯仰堵转逻辑，水平 ±128°、俯仰 5–85°。取消观察台三秒续约与命令三秒窗口，观察台退出不会关闭遥控。声音为观察台播放机器人麦克风首逻辑通道；本机模拟器使用 CoreAudio 输出，机器人自身扬声器仍无播放业务。实际硬件验收见交接记录最新段。
