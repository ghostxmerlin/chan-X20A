# 水平人脸追踪与模式遥控实现计划

> **For agentic workers:** Use the assigned file ownership below; preserve other workers' edits. Root integrates and independently verifies each boundary.

**Goal:** ASR open开启安全小幅水平追踪，next保留随机台词；遥控四向变为功能切换。

**Architecture:** M12提供新鲜检测/认人坐标，现有motor_task继续独占舵机UART。纯追踪策略决定有界yaw命令；独立模式协调器组合M12模式、遥控事件及听觉会话所有权。复用现有任务和紧凑网页，不改依赖、分区或SD资源。

**Tech Stack:** ESP-IDF5.5.4/C++、既有M12 UART、Node观察台、主机C++/Python/Node回归。

## 已定行为

- ASR open幂等开启追踪，close关闭；next随机台词并保留800ms等待、忙时丢弃/冷却。start/stop保留连续听觉显式启停。
- 遥控左切追踪，右切认人/主人对话，上切连续听觉，下切高级语音预留意图；高级模式明确未实现且不产生音频/网络/运动动作。中心保留屏幕开关。
- 遥控须回中后才能触发一次，按住/重连偏转/首帧不触发；对角输入拒绝。当前协议不能区分摇杆页和体感页，文档明确使用摇杆页。
- 用户确认：任意已登记人脸视为主人；确认主人后启动现有听觉/情绪回应，真正问答留后续。既有声纹只展示身份、回应所有人的规则保留。
- 认人需连续新鲜有效已知人脸结果，启动后由显式停止结束；手动stop后不自动重开。关闭认人只关闭其自己启动且仍持有的听觉意图，保护后来手动开启的监听/录入。
- 追踪+认人同时开启时使用recognize；只有追踪时detect；两者关闭时释放自己占用的M12。后台模式保留眼睛首页，旧网页手动预览独立。
- 追踪只yaw，以有效实测位置为中心±10°并服从机械限位；每次从有效实测起点到目标≤1°、更新间隔≥250ms，轨迹模型限速5°/s（不作为物理速度保证），中央死区约画宽8%。启动不回中、丢脸不搜索；每个未完成目标累计实际发令2秒内必须观察到至少0.3°朝目标的实际进展（小目标按剩余距离封顶），否则取消并锁存，关闭后重开才恢复。
- 仅消费启用后、模式匹配且时间晚于M12请求的新帧；反馈失效/过期、坐标过期、丢脸、模式变化、停用和网页手动接管均停止追踪输出。cancelMotion关闭扭矩，不能称物理锁止。
- 所有模式开机关闭，不新增NVS设置；追踪不得自动重启保存俯仰姿态。
