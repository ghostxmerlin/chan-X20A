# mind 第 0 阶段：只读分钟时间轴 + 模型能力探测 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 `hello` 库里已有的原始记录，每分钟算出一份“分钟包 + 强力元素”，在 Mac 监控页的“情景”页上看成一条不断档的时间轴；同时实测 aihubmix 上 luna / terra 能不能看图、能用哪一档结构化输出。

**Architecture:** 服务器上新增独立进程 `server/mind/`（systemd 单元 `soul-mind`），只读 `speech / tingwu / sounds / vision / sessions`，每分钟在 N+1 分 20 秒处理第 N 分钟，结果写 `mind_packages`（带版本）和 `mind_state`；本机 `127.0.0.1:52740` 提供只读 HTTP 接口。Mac 监控服务开一条 ssh 端口转发，把 `/api/mind/*` 代理到这个接口，新页面 `/mind.html` 显示时间轴和每分钟明细。本阶段不调用任何模型（探测脚本除外），不改固件、不改耳朵。

**Tech Stack:** Python 3.11 标准库 + pymongo 4.17（服务器 `~/soul-spike/.venv` 已装）；Node 24 标准库（监控页，无 npm 依赖）；unittest / `node --test`。

**Spec:** `docs/superpowers/specs/2026-11-10-mind-design.md`（第 2、3.1、3.2、3.7、8、11 节和开头的“修订”）。

## Global Constraints

- 原始表 `speech / tingwu / sounds / vision / sessions` mind 只读不写；mind 的表一律 `mind_` 前缀，带 `lane` 字段，本阶段只有 `"live"`。
- 什么都不删：分钟包重算产生新版本，旧版本保留。
- 密钥（`MONGO_URI`、aihubmix 的 `API_KEY` / `BASE_URL`）运行时从服务器上 hubmix 的 `~/aidea/agent/.env` 读（`settings.load_env`，行为与 `server/ear/tingwu.py` 的 `load_env` 相同；mind 不 import 耳朵的代码）；不进仓库、不打印。
- mind 的接口只监听服务器 `127.0.0.1:52740`，要求 `Authorization: Bearer <token>`，token 与耳朵同一个文件（`--token-file`）；Mac 侧经 ssh 转发访问，不开公网端口。
- 设置文件 `~/soul-mind/settings.json` 只在服务器上（含真实称呼）；仓库里只有 `server/mind/settings.example.json`，用占位名。仓库文档、测试数据不出现真实姓名、人脸数据、IP、MAC。
- 时区固定 `Asia/Shanghai`；一分钟 = `[minute_ms, minute_ms + 60000)`，正好落在 `:00.000` 的记录属于新的一分钟。
- 处理第 N 分钟的时刻 = N 分钟结束后 80 秒（`PROCESS_DELAY_MS = 80000`）。
- 服务器端不加新的 pip 依赖；Python 测试只用标准库（pymongo 在测试里用假对象替代）。
- 机器人侧规矩不受影响：本阶段不刷机。

## Review Focus

1. **没有结束时间的听觉会话**（耳朵崩溃或断网，`sessions.end_ms` 缺失）：覆盖不能一直延伸到现在。期望：止于“同一来源的下一个会话开始”或“该会话最后一条记录 + 120 秒”，取较早者，并标 `estimated: true`。测试在 Task 3。
2. **脸只有 found 没有 lost**（视觉连接断了、M12 掉线、事件丢失）：区间不能永远开着。期望：止于同会话里的 `m12_offline` / `vision_off`、视觉会话结束、或最后一次见到该脸后 120 秒，取最早者，标 `closed_by`。测试在 Task 2。
3. **同一分钟里跨两个会话**（重连）：句子和事件不能重复计数，代号不能撞。期望：代号全分钟唯一，记录按 `(collection, session, id)` 去重。测试在 Task 2。
4. **mind 停机后重启**：要补齐所有缺失的分钟，且内容没变的分钟不产生新版本。期望：指纹相同则跳过写入。测试在 Task 4。
5. **数据库暂时不通**：游标不能前进，进程不能退出。期望：本轮记错误、30 秒后重试，`/state` 显示错误。测试在 Task 4。

### Task 2: S1 分钟包

**Files:**
- Create: `server/mind/package.py`
- Test: `tests/test_mind_package.py`

**Interfaces:**
- Consumes: `Records.window`、`settings.*`（Task 1）。
- Produces: `package.build(window: dict, minute_ms: int, s: dict, lookback: dict) -> dict`。`window` 是本分钟 `[minute_ms, minute_ms+60000)` 的记录；`lookback` 是 `[minute_ms − 30 min, minute_ms + 60000)` 的记录（算脸的区间和“最后一次”用）。`BUILDER_VERSION = 1`。返回：

```
{"minute": int, "builder": 1,
 "speech": [{"code": "s1", "ref": {"c": "speech", "session", "id"}, "at": int, "text", "dur",
             "who": {"kind": "known|unsure|unknown|self", "name": str|None, "best": str|None, "score": float|None},
             "loud_db": float|None, "voice_p": float|None, "emotion",
             "tingwu": [{"code": "t1", "ref": {...}, "text"}]}],
 "tingwu_only": [{"code": "t2", "ref", "at", "text"}],
 "self_speech": [同 speech 结构，who.kind == "self"],
 "sounds": [{"kind", "label", "count", "max_loud_db", "codes": ["a1", ...]}],
 "faces": [{"code": "v1", "face": int, "session", "name": str|None, "from": int, "to": int,
            "open": bool, "closed_by": "lost|m12_offline|vision_off|session_end|tail",
            "gender": "m|f"|None, "age_group": str|None}],
 "persons": {"seconds": int, "ids": int},
 "unknown_faces": int,
 "events": {"vision_on": [...], "vision_off": [...], "m12_online": [...], "m12_offline": [...]},
 "codes": {"s1": {"c","session","id"}, ...},
 "warnings": [{"kind": "drift", "code", "seconds"}],
 "fingerprint": str}
```

规则（写进实现，测试锁定）：
- 句子按 `_wall` 归分钟；`self.sounding == True` 的句子进 `self_speech`，who.kind = `"self"`。
- who.kind：`speaker.band == "known"` → known（name = speaker.name）；`"unsure"` → unsure（best、score）；其余 → unknown。
- 听悟句挂到同会话里 `pos` 区间重叠最多的 SenseVoice 句下面；没有重叠的进 `tingwu_only`。
- 声音按 `kind` 合并：次数、最大 `loud_db`、代号列表。
- 脸的区间：在 lookback 里按 `(session, face)` 从 `face_found`（或第一条带该编号的事件）开始，`face_lost` 结束；名字取区间内最后一次 `face_named`（或事件里的 `name`）；性别、年龄段取区间内众数。没有 lost 的，按 Review Focus 第 2 条收口。只输出与本分钟有重叠的区间。
- 人形：本分钟内 `person_found`→`person_lost` 区间与本分钟重叠的秒数之和（多人重叠也只算墙上秒数），`ids` = 不同编号个数。
- 代号顺序：s、t、a、v 各自从 1 起，按时间排序；全分钟唯一。
- 记录按 `(collection, session, id)` 去重（vision 用 `(session, t_us, event, face, person)`）。
- `drift`：`|_drift| > drift_warn_s * 1000` 时加告警。
- `fingerprint` = sha1（排好序的引用列表 + 脸区间的 `(face, name, from, to)` + `BUILDER_VERSION`），十六进制前 16 位。

### Task 3: S2 覆盖和强力元素

**Files:**
- Create: `server/mind/strong.py`
- Test: `tests/test_mind_strong.py`

**Interfaces:**
- Consumes: `package.build` 的输出、`Records.window` 的 `sessions` 与 lookback 记录、settings。
- Produces: `strong.evaluate(pkg: dict, lookback: dict, minute_ms: int, s: dict, now_ms: int) -> dict`：

```
{"coverage": {"hearing_s": int, "vision_s": int, "m12_s": int, "estimated": bool},
 "time": {"label": "11-10 14:32", "weekday": 1..7, "work_hours": bool},
 "place": {"label": None, "source": "no_wifi_data"},
 "owner_face": {"last_ms": int|None, "in_view": bool, "codes": [...]},
 "owner_voice": {"known_last_ms": int|None, "likely_last_ms": int|None, "codes": [...]},
 "others": {"known": [display...], "unknown_faces": int, "unknown_voices": bool},
 "owner": {"state": "seen|just_left|likely_present|unknown|likely_absent|sensors_off", "why": str, "codes": [...]},
 "contradictions": [{"kind": "face_owner_voice_stranger", "codes": [...]}]}
```

规则：
- `hearing_s`：本分钟与听觉会话（`session` 不以 `-v<数字>` 结尾、来源以 `stackchan-` 开头）的重叠秒数之和（合并重叠区间）。会话结束 = `end_ms`；没有时 = min（同来源下一个会话的 `start_ms`，该会话最后一条记录 `_wall` + `open_session_tail_s`，`now_ms`），并置 `estimated`。
- `vision_s`：由 `vision_on` / `vision_off` 事件推出的开启区间与本分钟的重叠；lookback 里最早一条是 `vision_off` 或没有任何开关事件但本分钟有 `face_*` / `person_*` 事件时，视为整分钟开启（`estimated`）。`m12_s` 同理用 `m12_online` / `m12_offline`。
- 主人的名字：声纹名 ∈ `owner.voice_names`，脸名 ∈ `owner.face_names`；`others.known` 用 `people[*]` 的映射转成显示名，库里出现但没登记的名字原样显示。
- `owner_voice.likely_last_ms`：band 为 unsure、best ∈ owner.voice_names 的最后一句，**且**该句前后 `face_recent_min` 内主人的脸出现过（两路互相抬一档）；否则不算。
- 主人状态（从上到下取第一个成立的）：
  1. `hearing_s == 0 and vision_s == 0` → `sensors_off`
  2. 主人的脸区间与本分钟重叠 → `seen`
  3. 主人的脸最后时刻在 `just_left_min` 内 → `just_left`
  4. 主人声音（known）在 `voice_recent_min` 内，或 likely 在 `voice_recent_min` 内，或（主人的脸在 `face_recent_min` 内且本分钟有 `typing`）→ `likely_present`
  5. `max(hearing_s, vision_s) >= coverage_min_s` 且主人的脸和声音（known/likely）最后时刻都早于 `absent_after_min`（或从没有）→ `likely_absent`
  6. 其余 → `unknown`
- 矛盾：本分钟主人的脸在画面里，同时有 band = unknown、best ∉ owner 的句子 → 记一条（只记录，不裁决）。
