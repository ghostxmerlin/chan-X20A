# 随机台词与遥控上下屏蔽实施计划

> 按 superpowers:executing-plans 在当前会话连续实施，末尾做一次独立审阅。

**目标：** 屏蔽实体遥控上下；20条现有语音由网页点播/随机、ASR open随机触发，在StackChan本体播放。

**依据：** 用户2026-11-07最新请求。只关闭遥控俯仰，保留网页保存角和启动姿态；不再测试负载上下运动。

**实现选择：** 现有PCM共4.26MB，转24kHz单声道IMA ADPCM并随应用嵌入，预计1.1MB；解码成有界PCM后复用现有单播放worker/功放收尾。文件、生成资源仅.private，不提交音频。网页复用同源控制、鉴权和boot核对。固件选随机，避免连续同条；忙时拒绝，无队列/自动重试。ASR直接接收新open帧，启动和重连不播放。声音保持当前音量；不改M12/身份库。
