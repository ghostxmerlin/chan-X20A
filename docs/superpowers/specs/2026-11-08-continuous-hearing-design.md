# StackChan 连续听觉与声纹配置

用户要求先提交推送现有眼睛版本，再连接现有 sherpa-onnx 后端；配置区录入声纹，Unit ASR start 开始连续监听、stop 停止，后端情绪标签触发台词与配套眼睛。已确认回应所有人，声纹仅显示身份；不按转写关键词触发。638ea24 已在远端，StackChan 本体接回和部署仍按用户安排稍后进行。

## 数据流与范围

本体复用 collector 唯一麦克风采集，直连现有后端 WebSocket，网页仅配置和观察。网页关闭不停止已开启的连续监听。保留 ASR open 的随机台词及 800ms 等待、遥控仅左右、M12 手动模式，不恢复旧摄像头情绪框架。

本体持久化后端 ws/wss URL 与 token；仅主动保存后生效，任何启动均待机。token 不进入 URL、日志、HTTP GET、浏览器状态或子进程参数。POST 使用现有配对鉴权和 boot 校验。网页密码框空值表示保留已保存 token。后端兼容旧 Mac query token，同时支持严格 Bearer 认证。

配置区显示连接、监听、身份、最后转写/情绪、录入进度和错误；提供保存、开始/停止、录入姓名、明确同名替换及取消。姓名有界且不能作为文件路径。录入通过 StackChan 麦克风，暂停情绪回应，收集五段有效非自身语音；超时/取消/断线不保存半成品。完成后恢复录入前的监听意图；stop 总是结束两者。保存现有声纹前原子备份，文件原子替换。

## 实现默认值（由实现者选择）

- 24kHz 单声道、60ms Opus、40kbps VBR、complexity 0、AUDIO；当前 SDK 的 DTX 只支持特定低采样率 VOIP，故本版本关闭 DTX。不改依赖。
- SEA1 二进制帧：4 字节魔数、uint32 LE 序号、uint64 LE 首样本设备微秒、一个 Opus 包。服务端解码为16kHz。丢包显式记录并重置 VAD 分段，避免把跨缺口语音当作完整句子；不合成未采到的声音。
- 采集回调只拷贝到有界队列，网络/编码在独立任务；过期音频不追赶重播。掉线退避1/2/4/8/16/30秒，重新连接为新语音会话。录入中掉线终止该录入。每次 stop 立即失效旧会话和其回应，连接重试不能复活它。
- 自身播放及结束后1200ms都标记 self.sounding；标记随采集帧发送。后端在语音切片时保存重叠事实，异步推理完成后不根据当前 self 状态重新判断。自身语音不得录入或触发回应。
- 只用完整 speech/end 的有效人声、非空文本、非 neutral/unknown 的六类标签触发；身份不影响触发。丢弃过期结果，回应至少间隔10秒，忙时丢弃不排队。同一事件只触发一次。SenseVoice 情绪标签为实验性输出，不虚构可信度。
- 复用现有40条台词，根据标签选择一小组语义相近的台词，眼睛使用原有该台词映射。回应首个成功 PCM 输出才触发表情；stop 只取消该监听会话发起的声音/表情，不取消网页手动播放或 ASR open。
- 录入5句，每句1–12秒、总时限120秒；同名默认拒绝，显式替换先备份。异步旧推理结果不能落入新录入；连接关闭/取消后不能写声纹库。

## 交付与验证

固定 ESP-IDF 5.5.4、现有分区及依赖；新模块须适配剩余应用空间。主机回归覆盖协议、取消/代际、回声、自身标记、身份不设门槛、声纹原子保存、网页校验和秘密不入 argv。构建后核对 0x4f0000 应用槽容量。

服务器现有差异仅说明文字与默认端口；保留已运行端口及启动参数。部署前备份旧代码，核实未出现新远端改动；保留模型、token、声纹及录音。用真实服务器握手/24k Opus 输入和取消测试验证兼容性。真人身份准确率、硬件音频稳定性、实际屏幕效果和 ASR 串口联动须设备接回后独立验收，不能以主机测试替代。
