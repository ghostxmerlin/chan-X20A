# USB 串口监视台

用户要求：监视台改用串口，释放 ESP32-S3 网络能力和 RAM；旧网络监视代码保留但关闭，未来可恢复。延续此前“有变化就发”的方向。此文根据当前源码编写，不以旧 handoff 作为实现依据。

## 范围与实现决定

- 保留 8787 网页、SSE、全部现有控制与服务器 mind/TTS 功能。Mac 到机器人改 USB Serial/JTAG；机器人听觉、视觉上传、嘴的联网路径保留。
- 固件 `CONFIG_COLLECTOR_NETWORK_MONITOR` 默认关：不启动 8080/8081 HTTP、8082 UDP 发现和只供网络资产安装使用的 worker。保留源码和重新启用方法。串口断开不自动回落 Wi-Fi。
- 固定 IDF 5.5.4、锁文件、分区表、NVS、SD 内容；新版本 collector-0.4.81。不改变舵机策略、音频、摄像头采样策略。
- 在现有检出中新建功能分支，复用本机工具链与设备配置；不复制另一套私密文件/工具链。

## 通信协议（实现选择）

单个 Mac owner 打开按 USB 序列号匹配的设备。Python 标准库桥接字节流；不用浏览器 Web Serial，不修改 DTR/RTS，关闭 HUPCL。Node 负责协议与状态，退出释放端口，重连不重放控制。

帧头 16 字节：ASCII `SCM1`，kind u8（1=JSON、2=JPEG），version u8=1，reserved u16=0，payload length u32 LE，payload CRC32 u32 LE。payload 最大 131072 字节。JPEG payload = seq u32 LE + timestamp_us u64 LE + 原 JPEG。解析器有界、可从噪声/CRC 错误/截断重新同步；0.4.82 起主机帧组装期限为 1.5 秒，固件小命令仍为 250 ms、payload 另限 2048 字节。USB 单帧总发送最多约 1 秒，无进展约 100 ms 退出；实际包含底层一次写调用和任务调度余量。日志也封装成 JSON，由同一个发送者写 USB；启动前 ROM 日志由解析器跳过。主机必须完成 info 握手并建立 cache，才允许处理状态或发起 snapshot 重同步。

JSON RPC 请求含 `id`（正整数）、`op`。hello 带 nonce，返回现有 HMAC 身份证明；其后请求带绑定 token 和 boot_id。info 返回现有能力/目录。subscribe 开始推送并返回全量状态；ping 续租。租约 6 秒，Mac 每 2 秒续租；未订阅/租约到期不构造或排队遥测/图片。control 带 body（原 target 对象），复用共用业务分发与检查；reply 含 id/status/body。控制结果未知时不重试。

状态含 revision，增量含 base_revision，缺帧停用控制并请求全量；固件仅在发送成功后推进基线。状态首次全量，之后发送递归变化字段；数组原子替换，消失字段设 null，Mac 合并至缓存；每 30 秒补全量恢复基线。普通诊断采样 1 Hz，听觉/ASR 事件最多 50 ms 检查一次并独立推送，相机取最新已编码帧最高 5 Hz、不排积压。状态变化不假装来自新的传感器样本。心跳/连接活性与读数时间分开，保留各传感器自身的有效期判断。

固件控制应答从 HTTP 中抽出到共用响应类型，HTTP 与 USB 调用同一分发表。M12 上传事件队列不增加第二个消费游标，USB 读取状态快照；听觉/ASR 事件采用独立序号读取。

USB 收发 worker 栈 12 KiB 与大 JSON/临时帧使用 PSRAM；NVS 控制由独立 6 KiB 内部栈 worker 执行。收发小缓存有界。发送分块且有总时间预算，慢读/拔线丢弃待发遥测/图片、记录计数，不能阻塞采音、播放、舵机。日志格式化后放入有界队列，不能在业务任务里等待 USB。禁用网络监视时不分配其专用音频消费者历史缓存（若仍承担电平等功能，先保持共用部分，不删除采音）。

## 验收

主机：跨碎片/粘包/噪声/CRC/超长输入，身份不匹配，过期 boot，断连不重放，增量/全量合并及事件去重，无浏览器停止订阅，USB 返回有效期，旧 HTTP 选择模式回归。

设备：先验证不重启打开/关闭；刷前确认身份、活动 ota_1，备份旧槽，仅写 0x510000 并独立验证；串口身份握手、新版本/全量/增量/画面/无动作控制验证，断开/重连与无人读取验证；检查网络监听关闭，并对照内部 RAM、最大连续块、HTTP 任务是否消失。真实动作/听感与主机测试分别报告。

资产上传工具原来依赖 HTTP，默认关闭后不能继续使用；SD 现有资源保留，后续需要上传可显式重启网络监视构建。此次不新增 USB 大文件上传协议。
