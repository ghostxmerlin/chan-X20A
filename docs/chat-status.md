# 对话模式（chat）现状

写于 2026-11-14 晚。主人："你把 chat 目前的状态写下来，实在是内容太多了，我们后续再看是不是能优化。"
细节、讨论过程和审查记录都在后面"出处"里列的文件里，这里只写现在是什么样。

## 怎么用

1. 网页上先**打开听觉**（hello 重启后听觉默认是关的）。
2. 说 **play** 进对话模式（屏幕角标 CHAT），说 **pause** 离开。不会自动退出。
3. 直接说话。说完停一下，hello 用**无限**的声音回答一两句。

## 一句话怎么走（都已上线）

| 步骤 | 在哪 | 做什么 |
|---|---|---|
| 听 | hello → ear | 麦克风声音 → 降噪（GTCRN）→ 判断有人说话（Silero，静音 0.4 秒算说完）→ 转文字（SenseVoice）+ 认人（CAM++）+ 声音类别 |
| 推 | ear → mind | 只在对话模式里，识别完一句就推给 mind（`/chat/heard`），用 ear 自己的线程池，不耽误声音 |
| 筛 | mind `server/mind/chat.py` | 跳过：hello 自己的声音；它说话时听到的（等它说完再接）；空的、只有语气词的；太远的（比底噪高不到 `near_db` = 4 dB）；不像人声且不够响的 |
| 想 | mind | 上下文：情景、纪要、相关记忆（最多 3 条）、无限的说话方式、库里这个人的性格条目、最近 8 轮对话。用 `gpt-6.1-terra`（不推理）想 1–2 句，最多大约 60 字，不给健康建议 |
| 说 | mind → soul-tts → ear → hello | **流式**：模型想的时候就先接通语音合成，回答一出来第一句先送 |
| 记 | mind | 每一句都记进 `chat_turns`：听到的、回答的、跳过原因、响度、模型、花费、每一段的时间点 |

## 看得到的

- **hello 屏幕**（0.4.93）：左上角三个小圆点，对话模式里才有。
  - ○○○ 空闲，●○○ 在听，○●○ 在想，○○● 在说；
  - 三个点闪一下灰色 = 这句被跳过了。
- **网页 8787 台词面板**：
  - 实时的 听 / 想 / 说 / 跳过；
  - 最近一轮的时间线，每一段都标了毫秒数；
  - 被跳过的句子，带原因和响度；
  - "说完到开口"一共多少秒，流式的轮次带"流式"标记。

## 设置（`/speech/settings` 里的 `speech.chat`，改了马上生效，不用部署）

| 项 | 现在 | 说明 |
|---|---|---|
| `model` | `gpt-6.1-terra` | 离线实测（20 轮）最快、口吻最好：中位 1.31 秒，每轮约 0.06 美分。luna 1.59 秒，话多；haiku 不关推理会回空话，而且最慢 |
| `near_db` | 4 | 一开始是 8，主人自己的话多在 6–7 dB，被挡掉了，就降了 |
| `max_chars` | 60 | |
| `history_turns` | 8 | |
| `stream` | true | 设成 false 就退回整句合成 |

## 有多快

- 实测（流式上线前）：服务器这边从说完到开口 2.9–3.6 秒，主人感觉大约 4 秒。
- 每一段大约多久：
  - 听到并推给 mind：0.55–1.6 秒（识别偶尔慢到 0.8–1.5 秒）；
  - 模型：1.0–1.2 秒；
  - 语音合成到出声：0.9–1.3 秒。
- 流式预计能省 0.3 秒左右，**上线以后还没量**，要从 `chat_turns` 里看。
- 剩下的时间主要花在：百炼合成的第一段声音（约占 60%）、hello 开功放和 180 毫秒缓冲（约占 25–30%）、模型 1 秒多。

## 还不行的

- **打断不了**：hello 说话时听不见别人（没有回声消除，那段时间的输入被当成静音）。现在只能在网页上点"别说了"，或者说 pause。
- **进对话模式不会自动打开听觉**。
- **性格是借来的**：用的是呆呆（无限）那个角色的说话方式，没有单独的对话性格。那段角色文字本来是写来讲笑话的，回答可能会往"活多钱少"这类吐槽上偏。
- 模型爱揪住一条记忆反复说：已经限制到最多 3 条、要跟刚听到的话相关，效果还要看。
- 不能查东西、不能动 hello：没有工具调用，也没有 MCP。
- 一些小问题记在 `docs/backlog.md` 里"对话阶段指示"那一节。

## 下一步可以做的（主人还没排序）

1. **量一下流式上线后的真实耗时**，然后决定要不要让模型边写边念（大约省 0.4–0.6 秒，剩下最大的一块）。
2. **说"hello"打断它**：要改固件；也可以等以后做回声消除。
3. **单独的对话性格**：仍然用无限的嗓子，但不按讲笑话的写法。
4. **进对话模式时自动打开听觉**：要改固件。
5. **让模型能调用工具**：见 `docs/superpowers/specs/2026-11-14-llm-tools-catalog.md`。第一期是 7 个只读工具，不用改固件；先要测 terra 的函数调用。服务器现在控制不了 hello，所以动作类的工具要先在嘴的连接上加控制通道。
6. **收音**：采集音量调低 6 dB，hello 说话时就不会爆音；在录音上离线对比降噪效果；以后用喇叭参考那一路做回声消除。
