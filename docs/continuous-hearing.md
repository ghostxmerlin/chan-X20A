# 连续听觉（collector-0.4.30）

本体通过 Wi-Fi 直接连接 sherpa-onnx 后端。网页终端只负责配置和控制，不转发声音；关闭网页不结束已经开启的连续监听。

## 使用

1. 部署0.4.30及SD声音/眼睛资源后，打开 http://127.0.0.1:8787/ 。在“语音后端 · 配置与声纹”点击“使用本机现有后端”，或填写 ws/wss IPv4 地址与密钥。保存后待机，空密钥表示保留原值。
2. 说 **start**（Unit ASR工厂指令0x12）开始，或点击“开始连续监听”。说 **stop**（0x13）停止，也会取消本次声纹录入及该监听会话发起的台词/眼睛。开机默认待机。
3. 填写姓名，点击“录入五句话”。对着本体麦克风说五段自然语音，每段1–12秒，句间停顿；120秒未完成自动取消。录入期间不作情绪回应，完成后恢复原监听意图。
4. 同名资料默认保留；明确勾选“重新录入”才替换。后端先备份原声纹库，再原子保存。取消/断线/旧推理结果不能写入下一次录入。

**回应所有人，声纹仅显示身份。** 回应与录入使用独立于身份的 acoustic_band。known/unknown不改变同一段声学证据的触发条件。界面显示身份、最后转写、情绪、录入进度与连接错误；情绪标签是实验性分类，仅作互动参考。

| 后端标签 | 台词编号 | 眼睛 |
|---|---|---|
| happy | 6、23、28 | 沿用该台词的近似表情 |
| sad | 35 | 同上 |
| angry | 30、31、32 | 同上 |
| fearful | 4、26 | 同上 |
| disgusted | 24、25 | 同上 |
| surprised | 1、33 | 同上 |
| neutral / unknown | 不播放 | 不触发 |

只处理完整的人声结束事件和非空文字，5秒以上旧结果不回应；至少间隔10秒，忙时丢弃不排队。自身播放及结束后1.2秒的采集带 self 标记，在语音切片时冻结，避免延迟推理把自己的台词当外部声音。ASR open仍按原流程等待800ms后随机播放，网页普通点播不增加等待；手动眼睛优先。

## 接口与资源

- `POST /v1/hearing`：`{op:"config",url,token}`、`{op:"listen",enabled}`、`{op:"enroll",name,replace}`、`{op:"cancel"}`。均需原配对 Bearer 与当前 `X-Boot-Id`；不自动重发。info/telemetry的hearing字段不包含token。
- 24kHz mono Opus / 60ms / 40kbps VBR / complexity0 / AUDIO；当前SDK不在该模式开启DTX。复用原24k双通道采集的mic通道，独立有界队列、编码和传输任务。Opus worker 使用32 KiB PSRAM栈、优先级4（低于麦克风采集7），运行时报告栈余量和编码/发送/轮询耗时。
- SEA1包头：magic4字节、uint32 LE序号、uint64 LE首样本设备微秒、一个Opus包。后端解码16k；丢包显式记录并切断VAD段，前滚不越过缺口，旧排队语音清除。
- 单任务驱动IDF原生WebSocket transport，回调同步执行；连接/握手共享2秒预算，发送共享200ms预算，TCP_NODELAY避免小包等待；空轮询不阻塞，可读后用共享200ms预算接收完整消息。stop即刻失效会话并shutdown已建立socket。只接受IPv4，避免阻塞DNS绕过取消；wss仍验证系统证书。
- 不升级依赖或改分区。原首页120帧的32色索引由8位无损打包为5位，节省336480字节；全部897360个原索引的SHA一致。
- 后端沿用录音留存，不自动删除。SEA1头不写入Opus文件；文件保留24k输入率，事件采样索引仍以16k解码时间线计。

2026-11-08：0.4.30已经刷入并独立校验，SD已装入40台词和90眼睛。固定IDF构建通过；Python62项（58通过/4旧跳过）、Node49项通过。最终57.986秒并发监听窗口发送972个包，丢块/重连/SD错误均0；期间SD台词和happy眼睛同时运行，网页stop后回待机。后端对应实际记录976包/936960个16k样本，无错误。用户确认声音完整、眼睛正常。详细问题、驱动补丁和证据见[验证记录](collector-validation.md)。

服务器此前已在代码/声纹备份和远端漂移检查后部署，启动参数保持原值。真实服务验证Bearer、旧Mac query鉴权、错误token拒绝、24k Opus和启动/取消录入通过；原声纹库哈希未变。实体open配SD台词/眼睛已实测两次；实体start/stop尚待补验，网页链路已通过。没有新增真人五句话录入，身份准确率、情绪判断质量和40条逐条音质未验收。早先无回溯重启未完全归因；上述短窗口不代表长期稳定。浏览器宿主不可用，新网页仅做组件/API及实际服务文件回归，未作新界面视觉验收。

应用握手前断线的退避重置已修正：仅收到audio_ack后清除重试计数；握手成功前不采集音频。

## 实现复核中的决定

- 保持原分区和40条声音，通过无损索引打包释放空间；若实现不符会影响旧首页，已用所有原像素哈希回归。
- 使用播放会话归属取消旧声音，手动播放为独立归属；若边界不符会出现旧回应，主机策略测试覆盖取消与新会话。
- 配置暂限IPv4；若后端仅提供域名，须补可取消DNS支持。现有后端已核实符合。
- 关闭IDF `transport_ws`日志标签：其错误分支会打印含鉴权的完整请求。保留监视状态中的通用错误；代价是减少底层日志细节。
