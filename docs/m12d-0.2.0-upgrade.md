# M12 升级：m12d 0.1.0 → 0.2.0（事件）（2026-11-17）

M12 上的 m12d 已升级到 **0.2.0**。0.1.0 只发逐帧检测框；0.2.0 起，M12 还会把"发生了什么"直接报出来：有人来了、有人在看、点头、摇头、捂眼睛等。**旧的解析和命令完全不受影响**：只追加了字段和一种新的行。

权威协议仍是 m12d 仓库的 `docs/protocol.md`（§3.3 事件、§4 cfg）。0.2.0 在分支 `phase-6-events` 上，还没推送到 GitHub，本机副本在用户的 unitv2m12 工程里。本文是给 StackChan 侧对接用的摘要。

## 确认版本

发 `{"id":1,"do":"ver"}`，回复里应该是 `"ver":"0.2.0"`、`"git":"fed211c"`。`models` 里多了 `mini-xception`（笑的模型，默认不用，见下文）。

## 兼容性

- 新增一种推送行 `{"ev":{...}}`：顶层只有 `ev`，**没有** `f`、`hb`、`id`。按协议 §2，旧解析器会把它当成不认识的行忽略。
- 检测行里每张脸**追加**了 `yaw`、`pitch`、`roll`、`look`、`dist` 五个字段，原有字段不变。
- `cfg` **新增**了参数 `ev`、`wake`、`wake_cd`、`pose`、`smile`，原有参数和回复格式不变（回复里多了这几个键）。
- 原有命令（ping/ver/status/cfg/snap/learn/who/forget/faces）和心跳都不变。

## 新增 1：检测行里每张脸的姿态字段

| 字段 | 含义 |
|---|---|
| `yaw` | 左右转头角度（°），+ = 脸转向画面右侧 |
| `pitch` | 抬头 / 低头（°），+ = 抬头 |
| `roll` | 歪头（°），+ = 头顶倒向画面右侧 |
| `look` | 是否正对 StackChan（yaw、pitch 都在 ±15° 内） |
| `dist` | 估计距离（米），按脸宽粗算，未精确标定 |

角度是从五个关键点估出来的，精度有限，适合判断"大致朝向"，不适合精确测量。

## 新增 2：事件行

```json
{"ev":{"t":"nod","fr":8542,"face":3,"n":2}}
```

- `ev.t` 是事件类型，`ev.fr` 是帧号（和检测行的 `f` 同一计数）。坐标以 640×480 为准。
- 正常检测时，事件行在同一帧的检测行**之前**发出；待机时事件行是除心跳外唯一的推送。
- **不认识的 `t` 请忽略**，以后还会追加。

现在会发的事件：

| `t` | 意思 | 字段 | 实测情况 |
|---|---|---|---|
| `wake` | **只在待机时**：画面里有动静。M12 先自己看一眼再报 | `area`、`amt`；`faces`（认出来的带 `name`、`sim`）、`persons`；`cd` 冷却秒数；被转动时带 `"pan":true` | 走进、走过、转动都能叫醒 |
| `cover` / `uncover` | 有人捂住或用手遮住镜头 / 拿开 | `lum`；`uncover` 带 `dur`（捂了几秒） | 捂严和遮住都能检出 |
| `light` | 开灯 / 关灯 | `on`、`lum`；待机时开灯也带分析结果 | **还没实测**（白天测不了） |
| `look` / `look_end` | 某张脸正对 StackChan 0.5 s / 转开 | `face`；`look_end` 带 `dur` | 0.5 m 可用 |
| `nod` | 点头 | `face`、`n`（几下） | 0.5 m 可用 |
| `shake` | 摇头 | `face`、`n` | 0.5 m 可用 |
| `tilt` | 歪头（比平时倾斜 15° 以上并保持 0.3 s） | `face`、`side`（`"l"`/`"r"`） | 0.5 m 基本可用，见下文限制 |
| `enter` / `leave` | 有人来了 / 走了 | `face` 或 `person`：编号；`leave` 带 `dur` | 可用 |
| `near` / `far` | 靠近 / 离远（约 1 s 内距离变化 30%） | `face` 或 `person`；脸的带 `d`：`[前,后]` 米 | 可用 |

## 新增 3：cfg 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `ev` | true | 是否发事件行 |
| `wake` | true | 待机时是否检测动静、发 `wake` |
| `wake_cd` | 30 | 唤醒冷却的起始秒数（10–600） |
| `pose` | true | 检测行是否带姿态字段，是否发 look/nod/shake/tilt |
| `smile` | **false** | 笑的估计，**保持关闭**（没在设备上验证过，用户决定不做） |

## 对接时要知道的行为

**待机和唤醒**
- 发 `cfg det:false` 进入待机：神经网络停掉，只做很轻的动静检测，省电、降温。
- 有动静时 M12 先做一次人脸、人形检测，人脸库不为空时顺便认一下最大的脸，然后发 `wake`。一般在动静出现后 0.3–0.6 s 发出，最慢约 1.5 s。
- 报完进入冷却：从 30 s 开始，连续触发会翻倍，最长 600 s；安静 5 分钟恢复。每次重新进入待机时冷却重置。
- **M12 被转动（包括 StackChan 自己转头）也会唤醒**，带 `"pan":true`。StackChan 知道自己在转头，可以忽略这类 `wake`，或者转头时直接发 `cfg det:true`。
- 视野里有正在播放的屏幕时，待机会被反复唤醒（受冷却限制）。尽量别让屏幕出现在视野里，或者按 `area` 忽略屏幕方向的唤醒。

**进出（一个人只报一次进、一次出）**
- 脸和配对的人形算同一个人：谁先被确认，就用谁的编号报 `enter`。之后的 `near` / `far` / `leave` 都用这个编号，**即使检测行里的 `face[].id` / `person[].id` 已经换了新编号**。
- 歪头、转身导致脸丢了，或者坐得太近导致人形丢了，都不报。
- `leave` 会在人真正消失后**再等 1.5 s** 才发；这 1.5 s 里出现的人会被当成同一个人回来了。

**头部手势**
- `nod` / `shake` 在动作结束、头停稳约 **0.7 s** 后发出，不是动作一开始就报。连点两下、中间停顿约 0.5 s，仍算一次（`n:2`）。
- 门槛偏保守（用户要求宁可漏报不误报）：点头至少约 8°，歪头至少 15°。轻轻点一下可能不会报。
- 转头很侧、姿态不可信时，所有手势都不判；摇头进行中和摇头后 1 s 内不判点头。

**捂镜头**
- 白天用手遮住镜头时，画面不一定变暗，M12 靠"画面糊成一片"判断，所以 `cover` 的 `lum` 前后可能差不多。
- 镜头长时间贴近一面几乎没有纹理的白墙，也可能被报成 `cover`。

**串口带宽**
- 加了姿态字段后检测行变长了。115200 波特率约 11.5 KB/s，画面里 2 张脸加人形时约 10 KB/s，已经接近上限。请留意心跳里的 `drop`（因为通道太慢被丢弃的推送行数）。如果经常丢，可以发 `cfg pose:false`，代价是不再有姿态字段和 look/nod/shake/tilt 事件。

## 已知限制

- 头部手势只在约 **0.5 m** 处实测过。约 1 m 处人脸检测的置信度在门槛附近，脸时有时无，手势基本判断不了。
- 向右歪头时人脸检测有时会丢，歪头漏报，回正时偶尔会误报一次点头。
- `light` 还没在晚上实测。
- 今天的改动加了一些计算，**帧率还没复测**（0.1.0 有脸时约 15.0 fps，验收线 14.7 fps）。上机时请看心跳里的 `fps`。

## 试过但没有保留的

举手（`hand`）、脸旁挥手（`wave`）、伸手逗它 / 要抓它（`reach`）、笑（`smile`，保持关闭）、照片导入人脸库、场景识别。这些事件都**不会**发出。

## 建议的 StackChan 侧改动

1. `m12_protocol`：增加 `ev` 行的解析，按 `t` 分发，不认识的忽略；检测行的 face 结构加上五个姿态字段（可选）。
2. 交互层可以直接用这些事件：`look` 打招呼、`nod` / `shake` 当作是 / 否回答、`cover` / `uncover` 做躲猫猫、`enter` / `leave` 管理"有人 / 没人"状态、待机时用 `wake` 决定要不要醒来（`cfg det:true`）。
3. 网页监控页可以加一个事件列表（m12d 仓库里的 helloworld 页面有现成参考）。

## 上机注意

- M12 装回 StackChan 后由 Grove 口供电，**不要同时插 M12 的 USB-C**（两路 5 V 会接在一起）。
- 上电约 21 s 后 m12d 自动启动；没有 USB 网络时只走串口。
- 回退到 0.1.0：需要打开机壳插 USB-C，在 m12d 仓库的 master 分支上运行部署脚本。
