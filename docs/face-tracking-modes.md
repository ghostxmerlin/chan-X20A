# 水平追踪与模式开关

collector-0.4.35 将实体遥控的四向输入改为模式开关，直接转动保留在网页舵机控制中。所有新模式开机关闭；保存仰角和既有开机姿态不变，追踪不控制俯仰。

| 输入 | 行为 |
|---|---|
| ASR `open` / `close` | 开启 / 关闭水平追踪；重复 open 不重置保护 |
| ASR `next` | 随机播放40条SD台词之一，等待800ms避开模组OK，并配近似眼睛表情 |
| ASR `start` / `stop` | 开始 / 停止现有连续听力 |
| ASR `turn on` / `turn off` | 手动人脸预览 / 待机；退出后台追踪与认人模式 |
| 遥控左 | 开关水平追踪 |
| 遥控右 | 开关认人及主人听觉回应 |
| 遥控上 | 开关连续听力 |
| 遥控下 | 高级语音预留意图开关；尚无问答、音频或网络功能 |
| 遥控中心 | 原有屏幕开关 |

拨动一次后须松回中位，再拨动才切换。持续偏转、首包、断链后偏转和斜向输入不触发。请使用**摇杆页**：现有16字节协议无法区分摇杆与IMU页，不能声称体感输入已被隔离。

网页M12卡片提供追踪、认人对话及高级预留开关，并展示请求、实际输出状态、锚点、目标、主人身份及听觉归属。手动M12预览接管视觉；网页左右步进、保存仰角或停用舵机退出自动追踪。页面加载与重连不自动发送操作。

## 本体底部功能条

0.4.37新增贯通底边的320×3 px功能条，五个固定位置以1 px黑线分隔。自左向右：

| 颜色 | 点亮条件 |
|---|---|
| 白 | 水平追踪已请求开启；不代表舵机已经移动 |
| 蓝 | 连续听力已请求开启；不代表后端已经连接 |
| 红 | 声音作业已接受，包含等待、加载、播放和清理阶段；不证明实际发声 |
| 绿 | 首页正在显示眼睛或心/X表情 |
| 琥珀 | 认人模式已请求开启；不代表已认出主人 |

关闭的功能段保持近黑。功能条覆盖首页、摘要、日志和M12页面，关屏时隐藏，不拦截触摸；高级语音尚未实现，因此没有点亮段。各服务状态先在显示锁外采样，仅发生变化时重绘对应段。

## 追踪保护

0.4.44 起追踪只追方向，不瞄准：人脸中心偏离画面中心超过 130 px（约 40% 半宽）才发命令，每条命令从实测角度最近的 20° 档位再走一档（与网页左右按钮相同的档位和 speed=1000），命令间隔 ≥2.5 s；以开启后首次有效实测水平角为锚点，范围 ±60° 并服从机械限位。反向前取消旧运动，再从最新实测位置起步；没有从旧目标直接走向新目标的轨迹。中央死区保持，启动不回中，丢脸不搜索，关闭不自动归位。改为大档位的原因见验证记录：这颗 SCS0009 在负载下误差小于 4–5° 就停滞，1° 小步在出厂参数下不可能到位。

每个未完成目标累计实际发令 2 秒内应观察到至少 5° 朝目标的实测变化；不足 5° 的小目标按剩余距离封顶。软件轨迹结束不能替代真实进展。无进展、反馈突跳（相邻 100 ms 样本相差 >25°）、超锚点范围会锁存保护，需关闭后重开；回中、丢脸及模式/反馈缺口取消输出时暂停累计；恢复时继续原预算，反向目标从最新实测位置重新生成，也不补充预算。相邻两帧人脸中心跳变 >260 px 视为检测抖动，等待下一帧。取消动作会关闭扭矩，并非物理锁止。

## 认人和连续听力

任意已登记人脸均视为主人，两个不同的新鲜有效结果确认同一身份后，启动现有连续听力和情绪回应。未知人脸不启动，不新增或覆盖M12身份资料。追踪与认人同时开启时共用认人程序的框；只有追踪时使用检测程序。后台处理保留眼睛首页。

认人只决定自动进入听力；进入后仍回应所有人，声纹只显示身份。主人离开画面不会自动停听；显式stop后也不会被同一次认人自动重开，需关闭后重新开启认人。关闭认人仅停止它自身启动且仍持有的会话，后来手动start或声纹录入不会被误关。真正问答留待高级语音实现。

## 遥控器默认配置

本次已核对本体使用Channel 6、Receiver ID 1。新版sender没有有效保存值时默认6/1，直接进入摇杆页；A键循环为摇杆→IMU→设置→摇杆。设置页显示当前值，显式退出设置页时确认保存；默认启动和无变化的退出不写NVS。

配置使用独立命名空间和版本化记录，不自动擦除NVS。写入后读回核对；Flash错误可能部分生效，不能把错误等同于回滚成功，实际失败语义见sender测试和交接。若以后Wi-Fi频道改变，仍需进入设置页调整。

主机策略、真实Servo类和页面测试不替代实物方向、负载表现、真人认人及断电开机验收。当前部署与现场证据以[会话交接](session-handoff.md)和[验证记录](collector-validation.md)为准。

当前现场限制（0.4.38）：0.4.37读回证实位置模式限位正常、使能寄存器1且目标接受，但未产生朝目标的实测进展。0.4.38只加快同1°小步的缓动，保护不变；最终现场已读回完整目标raw461/使能1，反馈仍未朝目标推进，2秒保护停止。机械追踪未修复，当前追踪关闭/M12待机；不继续自动反复试转，不放大步长或延长保护，后续须有新的区分性证据。遥控器默认6/1和断电开机直接摇杆页已由用户确认。
