# 水平追踪与模式开关

collector-0.4.35 将实体遥控的四向输入改为模式开关，直接转动保留在网页舵机控制中。所有新模式开机关闭；保存仰角和既有开机姿态不变，追踪不控制俯仰。

| 输入 | 行为 |
|---|---|
| ASR `open` / `close` | 开启 / 关闭水平追踪；重复 open 不重置保护 |
| ASR `next` | 随机播放40条SD台词之一，等待800ms避开模组OK，并配近似眼睛表情 |
| ASR `start` / `stop` | 开始 / 停止现有连续听力 |
| ASR `turn on` / `turn off` | 手动人脸预览 / 待机；退出后台追踪与认人模式 |
| 遥控左 | 开关水平追踪 |
| 遥控右 | 开关认人及主人听觉回应 |
| 遥控上 | 开关连续听力 |
| 遥控下 | 高级语音预留意图开关；尚无问答、音频或网络功能 |
| 遥控中心 | 原有屏幕开关 |

拨动一次后须松回中位，再拨动才切换。持续偏转、首包、断链后偏转和斜向输入不触发。请使用**摇杆页**：现有16字节协议无法区分摇杆与IMU页，不能声称体感输入已被隔离。

网页M12卡片提供追踪、认人对话及高级预留开关，并展示请求、实际输出状态、锚点、目标、主人身份及听觉归属。手动M12预览接管视觉；网页左右步进、保存仰角或停用舵机退出自动追踪。页面加载与重连不自动发送操作。

## 追踪保护

以开启后首次有效实测水平角为固定锚点，范围±10°且服从机械限位；每次从实测起点到目标≤1°、命令间隔≥250ms。反向前取消旧运动，再从最新实测位置起步；取消后的正反目标可以相差2°，但没有从旧目标直接走向新目标的轨迹。轨迹模型限速5°/s，不是负载下实测速度保证。中央死区保持，启动不回中，丢脸不搜索，关闭不自动归位。

只使用启用后、M12模式请求已应用且新鲜的检测/认人框。M12时间是串口接收时间，协议没有相机采集时间或请求ID；同程序旧在途数据无法据此获得绝对关联保证。坐标跳变、反馈失效、过期及模式变化停止输出，临时反馈故障需两次新有效反馈才恢复。

每个未完成目标累计实际发令2秒内应观察到至少0.3°朝目标的实测变化；不足0.3°的小目标按剩余距离封顶。软件轨迹结束不能替代真实进展。无进展、反馈突跳、超锚点范围会锁存保护，需关闭后重开；回中、丢脸及模式/反馈缺口取消输出时暂停累计；恢复时继续原预算，反向目标从最新实测位置重新生成，也不补充预算。取消动作会关闭扭矩，并非物理锁止。

## 认人和连续听力

任意已登记人脸均视为主人，两个不同的新鲜有效结果确认同一身份后，启动现有连续听力和情绪回应。未知人脸不启动，不新增或覆盖M12身份资料。追踪与认人同时开启时共用认人程序的框；只有追踪时使用检测程序。后台处理保留眼睛首页。

认人只决定自动进入听力；进入后仍回应所有人，声纹只显示身份。主人离开画面不会自动停听；显式stop后也不会被同一次认人自动重开，需关闭后重新开启认人。关闭认人仅停止它自身启动且仍持有的会话，后来手动start或声纹录入不会被误关。真正问答留待高级语音实现。

## 遥控器默认配置

本次已核对本体使用Channel 6、Receiver ID 1。新版sender没有有效保存值时默认6/1，直接进入摇杆页；A键循环为摇杆→IMU→设置→摇杆。设置页显示当前值，显式退出设置页时确认保存；默认启动和无变化的退出不写NVS。

配置使用独立命名空间和版本化记录，不自动擦除NVS。写入后读回核对；Flash错误可能部分生效，不能把错误等同于回滚成功，实际失败语义见sender测试和交接。若以后Wi-Fi频道改变，仍需进入设置页调整。

主机策略、真实Servo类和页面测试不替代实物方向、负载表现、真人认人及断电开机验收。当前部署与现场证据以[会话交接](session-handoff.md)和[验证记录](collector-validation.md)为准。

当前现场限制（0.4.36）：持续1°目标得到ACK，但编码未变化，2秒累计活动保护触发，已关闭追踪。跟随效果与方向尚未通过；原因未定，先核对扭矩启用和目标量化，不自动放大步长或重复试转。遥控器默认6/1和断电开机直接摇杆页已由用户确认。
