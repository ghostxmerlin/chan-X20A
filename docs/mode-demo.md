# 模式切换本机演示（不用机器人、不用服务器、不花钱）

在自己的 Mac 上试网页的**模式条**和**快捷设置**（hello 模式第一步，1b 版：**以 hello 为准**）。

演示里有三样东西：

- **mind**：真正的模式代码（`server/mind/mode_store.py`、`billing.py`、`api.py`），数据库换成内存里的假库；
- **假 hello**：一个替身。它用 `server/mind/modes.py` 的规则自己切模式，切完像真 hello 一样报给 mind。0.4.92 固件用的也是这套规则；
- **观察台**：开在 **8807**，把假 hello 当机器人。模式条的点击和真机一样，走观察台的控制通道（`/v1/control {target: mode}`）发给 hello。

所以：

- 不连机器人，不连服务器，不调模型，不合成声音，什么都不花钱；
- 提前写、连续说只是开关会翻，后台不写也不播；
- 停掉就全忘，下次重新开始；
- 正在用的观察台（8787）和它的 `.private` 配置都不碰。

## 开始

打开“终端”，复制粘贴这两行（第一行换成你的仓库位置）：

```sh
cd ~/soul/chan-X20A
python3 -B scripts/mind-local-demo.py
```

看到这几行就好了：

```
mind 本机演示：127.0.0.1:52790，假 hello：127.0.0.1:52791，现在的模式 talk，设置 30 秒没动作自己关
本机模式演示观察台（假 hello，只有模式）：http://127.0.0.1:8807/
```

浏览器打开 **http://127.0.0.1:8807/** 。情景页 **http://127.0.0.1:8807/mind.html** 上也有同一条模式条。

开关条下面就是模式条（宽屏上是一行），从左到右：

- 现在的模式：彩色角标、中文名、什么时候谁切的，最后写“hello 上的模式”；
- 九个模式按钮；
- 右边小面板：计费开关（= 预设 9 / 0）和 0–9 预设；
- 最下面一行：刚才那一下的结果。

## 可以试的

1. **一开始全开**：mind 一启动就跑一遍预设 9（主人 2026-11-14 晚：“启动默认全开”），开关条上听悟、识别、纪要、情景都是开的。假 hello 刚开机，开机也算进入脱口秀，所以提前写、连续说也开着，右边小面板写“提前写 开 · 连续说 开”，计费开关写“计费 全开”。
2. **进出模式**：点“围观”。最下面写“已发给 hello：围观”，一秒左右角标变绿 `MEET`。再点一次“围观”= 离开，到 IDLE。点“字幕 中→英”，再点“字幕 英→中”，只换方向。
3. **点当前模式 = 离开**：在脱口秀里点“脱口秀”，到 IDLE。离开脱口秀时，提前写、连续说就关了。
4. **回脱口秀**：从别的模式点“脱口秀”，提前写、连续说又开。
5. **预设**（右边“预设 0–9”小框，点开才看到）：
   - `0` = 花费全关：所有付费开关关掉，计费开关写“计费 全关”。计费开关**不拦任何东西**：开关条上的单个开关（情景、纪要……）照样能一个个点开；进脱口秀照样打开提前写、连续说。点一下计费开关 = 预设 9。
   - `9` = 花费全开：服务器那一半照做。机器人那一半（听觉、视觉）会写“没成”，因为演示里没有真机器人。这是对的。
   - `4`–`8` = 让 hello 进 IDLE / 围观 / 陪伴 / 字幕 中→英 / 字幕 英→中。数字只负责“进”：已经在那个模式里，再按也不会离开。
   - `1`–`3` 是灰的（空）。
6. **设置会自己回去**：点“设置”，模式条写“关了回到 脱口秀”。30 秒不动，它自己回到原来的模式，来源写“超时”。这个计时在 hello 上，和真机一样。
7. **事件驱动**：点“事件驱动”，角标写 `AUTO`。
8. **记录**：“最近 N 次”点开，能看到 mind 收到的每一次报告。
9. **结果行**：可以点 × 关掉。过一会儿 hello 自己又变了（比如设置超时），旧的那行会自己消失。
10. **窄屏**：窗口拉窄到手机宽度，模式条会自动换行。

演示里别的面板（机身、视觉、听觉、台词）大多是空的或写“未连接”，这是正常的。在脱口秀里“说一轮”会说没配置 soul-tts，不会花钱；不在脱口秀时台词按钮是灰的。

**接真 hello 的时候**：0.4.91 还没有模式，模式条会写“hello 固件还不支持模式（等 0.4.92）”，按钮是灰的。hello 没连上时，模式条显示 mind 最后记下的模式，按钮也是灰的。

## 停止

回到运行演示的终端窗口，按 **Ctrl+C**。演示的 mind 和 8807 的观察台一起停，8787 不受影响。

## 可选参数

```sh
python3 -B scripts/mind-local-demo.py --settings-timeout 10   # 设置 10 秒没动作就回去（真实是 5 分钟）
python3 -B scripts/mind-local-demo.py --monitor-port 8817     # 8807 被占用时换一个端口
python3 -B scripts/mind-local-demo.py --no-monitor            # 只开演示 mind，打印观察台的启动命令
```

`--no-monitor` 打印的那一行带着这次演示的两个临时口令（演示 mind、假 hello），只对这次演示有用，停掉就失效，演示也花不了钱。

## 原理

观察台看到下面这些环境变量时，进入演示：

- `SOUL_MIND_LOCAL=http://127.0.0.1:<端口>` 和 `SOUL_MIND_LOCAL_TOKEN`：直接用本机回环 HTTP 连演示 mind，不走 ssh；
- `SOUL_DEMO_ROBOT=http://127.0.0.1:<端口+1>` 和 `SOUL_DEMO_ROBOT_TOKEN`：机器人换成假 hello。假 hello 只回 `/v1/info`、`/v1/telemetry`（带 `mode`）和 `/v1/control {target: mode}`；
- `SOUL_MONITOR_PORT`：观察台自己的端口。

演示时观察台不读 `.env` 和 `.private/stackchan-monitor.json`，也不打开机器人的 USB 口或 Wi-Fi 连接。两个地址都只接受本机回环，别的地址直接拒绝。没设这些变量时，观察台和以前完全一样。
