# 模式切换本机演示（不用机器人、不用服务器、不花钱）

在自己的 Mac 上试网页的**模式条**和**快捷设置**（hello 模式第一步）。演示用的是 mind 真正的模式代码（`server/mind/modes.py`、`mode_store.py`、`billing.py`、`api.py`），只是数据库换成内存里的假库，所以：

- 不连机器人，不连服务器，不调模型，不合成声音，什么都不花钱；
- 提前写、连续说只是开关会翻，后台不写也不播；
- 停掉就全忘，下次重新开始；
- 正在用的观察台（8787）和它的 `.private` 配置都不碰，演示开在另一个端口 **8807**。

## 开始

打开“终端”，复制粘贴这两行（第一行换成你的仓库位置）：

```sh
cd ~/soul/chan-X20A
python3 -B scripts/mind-local-demo.py
```

看到这两行就好了：

```
mind 本机演示：127.0.0.1:52790，现在的模式 talk，设置 30 秒没动作自己关
本机模式演示观察台（没有机器人）：http://127.0.0.1:8807/
```

浏览器打开 **http://127.0.0.1:8807/** 。情景页 **http://127.0.0.1:8807/mind.html** 上也有同一条模式条。

开关条下面就是模式条（宽屏上是一行）：左边是现在的模式（彩色角标、中文名、什么时候谁切的、机器人有没有显示）和九个模式按钮，右边小面板是计费总闸和 0–9 预设，最下面一行写刚才那一下的结果。

## 可以试的

1. **进出模式**：点“围观”→ 角标变绿 `MEET`；再点一次“围观”= 离开 → IDLE。点“字幕 中→英”，再点“字幕 英→中”= 只换方向。
2. **点当前模式 = 离开**：在脱口秀里点“脱口秀”→ IDLE。
3. **进脱口秀会打开提前写 + 连续说**：从别的模式点“脱口秀”，最下面写“提前写、连续说打开，家人声音关”，右边小面板也变成“提前写 开 · 连续说 开”。离开脱口秀，这两个就关。
4. **预设 0 = 花费全关**：按 `0` → “计费总闸 关 · 现在不花钱”。这时：
   - 再进脱口秀，写“计费关着：提前写、连续说没开”；
   - 开关条上的“情景”“纪要”点了会被拒绝（计费关着）；“听悟”“识别”在演示里本来就是灰的（没有机器人）。
   - 点“计费总闸”可以再打开。
5. **设置会自己回去**：点“设置”，模式条写“关了回到 脱口秀”。30 秒不动，它自己回到原来的模式，来源写“超时”。
6. **事件驱动**：点“事件驱动”，角标写 `AUTO`。
7. **预设 1 / 9 的机器人那一半**：按 `1` 或 `9`，服务器那一半照做（总闸关 / 开、提前写、嘴切 TTS 等），机器人那一半会写“听觉（本体听觉）没成：请恢复监控并等待新的机器人状态；视觉（摄像头）没成：……”。这是对的：演示里没有机器人，网页照实写哪一步没成，不排队、不重试。
8. 0–9 在右边“预设 0–9”小框里，点开才看到；5–8 是灰的（还没定义）。“最近 N 次”点开能看到每一次切换。结果那一行可以点 × 关掉；别处（DualKey、机器人）改了模式，它自己会消失。
9. 窗口拉窄到手机宽度，模式条会自动换行。

模式条上一直写“机器人离线（连上后照这个显示）”：演示里没有机器人，这是对的，不是坏了。

演示里别的面板（机身、视觉、听觉、台词）大多是空的或写“未连接”，这是正常的。“说一轮”会说没配置 soul-tts，不会花钱。不在脱口秀时台词按钮还没变灰，这是下一步（B2）的事。

## 停止

回到运行演示的终端窗口，按 **Ctrl+C**。演示的 mind 和 8807 的观察台一起停，8787 不受影响。

## 可选参数

```sh
python3 -B scripts/mind-local-demo.py --settings-timeout 10   # 设置 10 秒没动作就回去（真实是 5 分钟）
python3 -B scripts/mind-local-demo.py --monitor-port 8817     # 8807 被占用时换一个端口
python3 -B scripts/mind-local-demo.py --no-monitor            # 只开演示 mind，打印观察台的启动命令
```

`--no-monitor` 打印的那一行带着这次演示的临时口令，只对这次演示的 mind 有用，停掉就失效，演示 mind 也花不了钱。

原理：观察台看到环境变量 `SOUL_MIND_LOCAL=http://127.0.0.1:<端口>`（加上 `SOUL_MIND_LOCAL_TOKEN`、`SOUL_MONITOR_PORT`）时，直接用本机回环 HTTP 连演示 mind，不走 ssh，不读 `.env` 和 `.private/stackchan-monitor.json`，也不打开机器人的 USB 口或 Wi-Fi 连接。只接受本机回环地址，别的地址直接拒绝。没设这个变量时观察台和以前完全一样。
