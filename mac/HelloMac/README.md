# hello 的 Mac 版（2026-11-19 夜）

把 hello 机身固件做的事搬到 Mac 上：Mac 的麦克风当耳朵，摄像头当眼睛（本机认人），扬声器当嘴，窗口就是机器人那块屏幕。服务器把它当成一台机器人，但它有**自己的一套服务和自己的一份数据**，和真机器人互不干扰。

## 用起来

```sh
mac/HelloMac/setup.sh        # 只要一次：写配置，把耳朵的令牌拷到本机（600 权限，不打印）
mac/HelloMac/build-app.sh    # 编出 mac/HelloMac/build/hello.app
open mac/HelloMac/build/hello.app
mac/HelloMac/monitor-mac.sh  # 可选：Mac 那套的观察台 http://127.0.0.1:8788/（开关、日志、漏答漏斗）
```

第一次打开会问麦克风和摄像头权限。两个窗口：

- **hello**：机器人的屏幕放大两倍。左上角模式（DOCK 绿色），中间眼睛（v14 / v05 / v18，自己会换表情），下面一行字（在听、调试中……），再下面对话阶段的小点，最底下一行是连接状态和麦克风音量。
  **点一下 = 单击屏幕，连点两下 = 双击**。点屏幕聊天模式下，点一下就开始聊；它在说话时点一下就停。
- **hello 设置**：选麦克风、摄像头、眼睛款式；听觉 / 摄像头 / 上传画面 / 认人的开关；「说 hello」（模拟语音模块的唤醒词）、单击、双击、全开 9、全关 0；录人脸（看摄像头 5 秒）、录声纹（说五句话）；认人门槛；下面是日志（听到的话、认出的人和相似度、录入进度）。

## 做了什么（和机器人对照）

| 机器人 | Mac 上 |
| --- | --- |
| 麦克风 24 kHz → Opus 60 ms → 耳朵（SEA1） | 选定的麦克风 → 同样的格式；自己说话时报「在出声」，耳朵那段时间不听 |
| 扬声器：放耳朵送来的 Opus 流，回报播放进度 | 同样：攒够 180 毫秒开始放，按实际播完回报，单击能打断 |
| 屏幕：眼睛、模式、字、阶段点、视觉爆发 | 同样（同一套眼睛动图） |
| 触摸：单击 / 双击，模式规则 | 鼠标单击 / 双击；模式规则逐条照搬，2100 条标准向量全部一致 |
| 机身摄像头：画面变了才传，每秒最多一张 | 同样的判定（16×12 亮度格，6 格变化） |
| M12 认人：人脸出现 / 认出 / 陌生 / 离开 | Apple 人脸检测 + 本机人脸库（每人最多 20 张，只存特征数字，不存照片） |
| 声纹 | 走耳朵的声纹录入，存在 Mac 那套耳朵自己的声纹库（复制时带上了现有的） |
| 服务器发来的命令：表情、字、台词、点头、摇头、转头、音量、学人脸、状态 | 表情和字照做；点头摇头转头用眼睛动作代替（没有舵机）；放 SD 台词：用打包进 app 的 80 段 |
| 开机给 mind 发 9（全开花钱的开关） | **默认不发**（设置文件里 powerOnNine） |
| 机身摄像头的图约 5.7 KB | 同样压到 8 KB 以内（画面杂就降质量） |
| 听完一句话的反应：「嘴」在录音档时按情绪播一段台词（等屋里安静 1.5 秒，10 秒一次，开心隔次），否则眼睛按情绪动 | 同样的规则；80 段台词打包进 app（来自本机 .private，不进仓库） |
| 语音模块的口令（hello、play、turn left、zero…nine、音量…） | 设置里「语音口令」（默认关）：系统识别器**只在本机**识别英语，整句正好是口令才算；本机不能识别就不开 |

没做的：舵机、身体感觉（摇晃、拿起、靠近）、叫名字开始聊天。

## 服务器上的那一套

`tools/mac/clone_db.py` 把数据库 `hello` 原样复制成 `hello_mac`（复制时花钱开关全关、没到点的提醒停掉）；`tools/mac/deploy_stack.sh` 在服务器上起三个只听内部端口的服务，Mac 经 SSH 转发连过去，不开公网端口：

| 服务 | 端口（服务器 127.0.0.1） | 说明 |
| --- | --- | --- |
| soul-spike-mac | 52832（ask 52843） | 耳朵，数据库 hello_mac，录音在 ~/soul-spike-mac |
| soul-mind-mac | 52840 | mind，设置在 ~/soul-mind-mac |
| soul-tts-mac | 52850（嘴 52851） | TTS 只认一台设备，所以单独一份 |

关键词耳朵、模型、垫话、人设、令牌两套共用（只读）。停掉：`tools/mac/deploy_stack.sh --stop`；更新代码后再跑一次 `deploy_stack.sh`。服务是临时注册的，服务器重启后要重跑。

**花钱**：两套各有各的每日上限；Mac 那套的花钱开关默认全关。点屏幕聊天时，Docking 关着的话点一下会把 Mac 那套的 Docking 打开（和机器人一样）。

## 测试

```sh
cd mac/HelloMac
swift run HelloSelfTest                 # 协议层：模式规则 2100 条、Opus、三种包格式、三条连接、人脸轨迹、变化判定
swift build && .build/debug/HelloMac --selftest   # 麦克风转码、扬声器回报（离线渲染，不出声）
swift run HelloProbe --tts              # 端到端：用系统 say 合成一句话当麦克风，连服务器上 Mac 那套，再让 TTS 回一句
```

只装了命令行工具（没有 Xcode），所以测试是可执行程序。libopus 来自 Homebrew，静态链进 app。
